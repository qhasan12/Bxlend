✅ Frontend

- Built using **HTML**, **CSS**, **Bootstrap**.
- To run the frontend:
  - Open the `index.html` file with **Live Server** in VS Code or any similar tool.

✅ Backend

- Built using **Node.js** (JavaScript).
- To run the backend:
  - Open a terminal in the backend directory.
  - Run the following command:
    ```bash
    node index.js
    ```
